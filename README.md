# Portfolio — Lucas Damstén

Site vitrine en HTML/CSS/JS pur, pensé pour être hébergé gratuitement avec **GitHub Pages**.

## Fichiers

- `index.html` — le contenu et la structure des 4 sections (Accueil, Projets académiques, Qui est Lucas, Projets personnels)
- `style.css` — toutes les couleurs, polices et mises en page
- `script.js` — gère les points cliquables ("hotspots") sur les images
- `images/` — dossier où placer vos photos

## Mettre le site en ligne (GitHub Pages)

1. Créez un dépôt GitHub (ex : `lucas-portfolio`) et mettez-y ces fichiers.
2. Dans le dépôt : **Settings → Pages → Branch: main → dossier `/root`** → Save.
3. Le site sera visible après 1-2 minutes à l'adresse indiquée par GitHub (ex : `https://votre-pseudo.github.io/lucas-portfolio/`).

Voir les explications détaillées données dans la conversation pour la suite (modifier le texte, ajouter des photos, régler les hotspots, etc.).
